# CE301 Individual Capstone Project - Create A Game That Modernizes The Arcade Shoot Em' Up Genre

## Links
Jira - https://harry-johnson-essex-capstone.atlassian.net/jira/software/projects/CAP/boards/1

GitLab - https://cseegit.essex.ac.uk/24-25-ce301/24-25_CE301_johnson_harry_g

## Brief Description
Create a game that attempts to modernize the arcade shoot 'em up genre by implementing many elements and features from more modern and popular genres.

## What Is Included
- Unity Project files.
- Game design document.
- UML Diagrams PDF.

## How to Run The Game
Currently the game can only be run inside the Unity editor or built inside the Unity editor then run. To open the project in the Unity editor. Download and install the Unity editor (version 6000.0.32f1 LTS) then add the repo folder as a project inside the Unity Hub or open the folder inside the editor.

If you plan to build the game inside the editor do not expect perfect results.
